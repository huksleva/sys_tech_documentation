# Практическая работа: основы Zettelkasten

**Тоц Леонид Александрович, ИВТ-2. 21 октября 2026 г.**

Сеть знаний о разработке Alien Invasion на основе материалов ЛР5 и ЛР6: 35 атомарных карточек, 7 тематических типов, 5 идей улучшения, 4 служебные заметки. Существующие ЛР не изменены.

## Как открыть

В Obsidian выберите «Открыть папку как хранилище» и укажите именно `vault`. Откройте [Старт.md](vault/Старт.md). В Zettlr добавьте `vault` как рабочую папку: карточки используют обычные Markdown-файлы и ссылки на числовые ID вида `[[20261021000009]]`.

В Zettlr убедитесь, что распознавание ID настроено на 14 цифр (регулярное выражение `[0-9]{14}`). Сначала проверьте переход из карточки 20261021000009 к 20261021000031. Интерфейс и названия настроек могут различаться по версии.

Для живого графа Obsidian используйте Graph view; фильтр `-path:sources` исключает исходные документы, Tags добавляет узлы общих тегов. Дополнительные плагины не нужны. Готовые графы уже есть в `vault/attachments`.

## Проверить и пересобрать

Из этой папки, с Python 3.11+:

```powershell
python scripts/build.py --validate-only
```

Для пересборки графов, документов, PDF и архива нужны `Pillow`, `reportlab`, `pypdf`:

```powershell
python scripts/build.py
```

Проверка анализирует ссылки, уникальность ID, теги, входящие связи, связность и соответствие графа исходным карточкам. Карточки являются редактируемыми первоисточниками; сборка не перезаписывает их. Снимки `vault/sources` исключены из метрик карточек.
