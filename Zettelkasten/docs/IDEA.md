## Индикатор залпа объяснит недоступный выстрел

[Карточка 20261021000031](../vault/20261021000031.md).

Показать в HUD три сегмента слотов: занятый слот заполнен, свободный пуст; рядом число свободных слотов. Гипотеза: игрок быстрее поймёт, почему Space иногда не создаёт пулю.

Связка «лимит залпа + непрерывный HUD + эпизод непонимания» дала эту идею. Проверка прототипа: при 0/1/3 активных пулях сегменты соответствуют группе; в пробной партии игрок объясняет причину отказа до подсказки.

- [20261021000009](../vault/20261021000009.md) SRS - Четвёртая активная пуля не создаётся. Определяет единственный источник числа занятых слотов.
- [20261021000008](../vault/20261021000008.md) GDD - HUD показывает состояние без выхода из партии. Даёт место для индикатора.
- [20261021000013](../vault/20261021000013.md) SRS - Состояние нельзя передавать только цветом. Требует формы и числа помимо цвета.
- [20261021000027](../vault/20261021000027.md) MKT - Отзыв полезнее привязывать к наблюдаемому затруднению. Задаёт способ проверки понятности.

## Предупреждение о низком флоте даст время отреагировать

[Карточка 20261021000032](../vault/20261021000032.md).

Если нижний ряд флота пересекает согласованную опасную высоту, показать значок и текст «Флот близко». Предупреждение не меняет правила столкновений и начисления очков.

Идея получена из связи спуска флота с читаемостью состояния. Проверка: выше порога сообщения нет, ниже порога есть, после нового флота оно сбрасывается. Полезность порога нужно оценить в пробной партии.

- [20261021000005](../vault/20261021000005.md) GDD - Разворот флота приближает угрозу. Задаёт приближение угрозы.
- [20261021000008](../vault/20261021000008.md) GDD - HUD показывает состояние без выхода из партии. Даёт место обратной связи.
- [20261021000013](../vault/20261021000013.md) SRS - Состояние нельзя передавать только цветом. Не позволяет ограничиться миганием цветом.
- [20261021000027](../vault/20261021000027.md) MKT - Отзыв полезнее привязывать к наблюдаемому затруднению. Проверяет, замечает ли игрок предупреждение вовремя.

## Таймер восстановления сохранит обработку событий

[Карточка 20261021000033](../vault/20261021000033.md).

Заменить sleep(0.5) в обработке потери корабля состоянием RECOVERING с временем окончания. До истечения таймера движение и выстрел запрещены, но события выхода и отрисовка обрабатываются в обычном цикле.

Это перенос проектной идеи ЛР5 в фактический код ЛР6. Проверка: событие выхода принимается во время восстановления, повторная угроза не списывает запас, по таймеру управление возвращается один раз.

- [20261021000020](../vault/20261021000020.md) SDD - Порядок операций кадра влияет на результат. Объясняет, почему блокирование останавливает следующий кадр.
- [20261021000010](../vault/20261021000010.md) SRS - Неактивная партия запрещает движение и выстрел. Задаёт запрещённые действия.
- [20261021000022](../vault/20261021000022.md) DEV - Расхождение кода и проекта требует явного решения. Показывает исходное расхождение проекта и реализации.
- [20261021000021](../vault/20261021000021.md) DEV - Проверка правила начинается с наблюдаемого результата. Требует сценариев проверки переходов.

## Временной шаг отделит движение от частоты кадров

[Карточка 20261021000034](../vault/20261021000034.md).

Хранить скорости в пикселях за секунду и умножать их на длительность кадра dt. Для сохранения текущего темпа при 60 FPS исходные значения в пикселях за кадр сначала умножаются на 60.

Связь кадровой скорости с ограничителем FPS показывает риск замедления на медленном ПК. Проверка модели: за одну секунду при шагах 1/30 и 1/60 смещение совпадает в заданной погрешности. Большой dt и пропуск коллизий потребуют отдельного решения.

- [20261021000014](../vault/20261021000014.md) SRS - Ограничение FPS не доказывает производительность. Показывает, почему ограничитель не гарантирует одинаковый темп.
- [20261021000017](../vault/20261021000017.md) SDD - Дробная координата сохраняет малое перемещение. Сохраняет дробную позицию между шагами.
- [20261021000020](../vault/20261021000020.md) SDD - Порядок операций кадра влияет на результат. Определяет место вычисления dt.

## Локальное сохранение продлит жизнь рекорда

[Карточка 20261021000035](../vault/20261021000035.md).

Сохранять рекорд в локальном JSON-файле при улучшении и читать при запуске. Повреждённый или отсутствующий файл должен давать начальный рекорд 0 и понятную диагностику без запрета партии.

Идея связывает стимул повторной попытки с офлайн-ограничением. Проверка: рекорд переживает перезапуск, новая партия его не сбрасывает, неверный JSON не ломает запуск. Это расширяет границы ЛР5 и требует обновить её требование о сроке хранения.

- [20261021000007](../vault/20261021000007.md) GDD - Рекорд процесса сохраняет смысл повторной партии. Задаёт текущий срок жизни рекорда.
- [20261021000011](../vault/20261021000011.md) SRS - Повторный Play сбрасывает только данные партии. Сохраняет правило повторной партии.
- [20261021000012](../vault/20261021000012.md) SRS - Базовая игра работает без сети. Исключает необходимость сетевого сервиса.
- [20261021000030](../vault/20261021000030.md) SUP - Патч должен сохранять проверяемые правила. Требует проверки поставки и миграции поведения.
