# SDD: Alien Invasion

Устройство фактической реализации ЛР6. Сборка из атомарных карточек от 21.10.2026.

Документ сохраняет статусы карточек. Проектные требования, выводы и предложения не являются утверждением о готовой реализации. Источники и подробные связи доступны по ссылкам.

## Контроллер координирует объекты одного кадра

[Карточка 20261021000015](../vault/20261021000015.md).

AlienInvasion создаёт настройки, статистику, корабль, группы пуль и пришельцев, HUD и кнопку Play. Этот объект определяет порядок обработки ввода, обновления объектов и вывода кадра.

Координация в одном месте позволяет проследить путь от события к изменённому состоянию. Изменение правил отдельного объекта следует оставлять в его классе, если оно не требует согласования всей сцены.

- [20261021000016](../vault/20261021000016.md) SDD - Флаги удержания отделяют события от движения. Даёт входные события для текущего кадра.
- [20261021000018](../vault/20261021000018.md) SDD - Групповая коллизия начисляет очки за все цели. Согласует результат попаданий между группами.
- [20261021000020](../vault/20261021000020.md) SDD - Порядок операций кадра влияет на результат. Определяет порядок обновления.
- [20261021000024](../vault/20261021000024.md) DEV - Небольшой вертикальный срез проверяет идею быстрее. Помогает выбрать небольшой вертикальный срез разработки.

## Флаги удержания отделяют события от движения

[Карточка 20261021000016](../vault/20261021000016.md).

KEYDOWN включает флаг направления, KEYUP снимает его, а Ship.update использует текущее сочетание флагов каждый активный кадр. Поэтому движение продолжается между отдельными событиями клавиатуры.

При центрировании корабля оба флага сбрасываются: удержание, начатое в предыдущем состоянии партии, не переносится в новое положение.

- [20261021000003](../vault/20261021000003.md) GDD - Горизонтальное движение ограничено игровым полем. Реализует непрерывное горизонтальное управление.
- [20261021000010](../vault/20261021000010.md) SRS - Неактивная партия запрещает движение и выстрел. Запрещает включать движение в неактивной партии.
- [20261021000017](../vault/20261021000017.md) SDD - Дробная координата сохраняет малое перемещение. Передаёт направление в точное вычисление координаты.
- [20261021000015](../vault/20261021000015.md) SDD - Контроллер координирует объекты одного кадра. Показывает границу между контроллером и объектом.

## Дробная координата сохраняет малое перемещение

[Карточка 20261021000017](../vault/20261021000017.md).

Ship хранит горизонтальную позицию как float, а для отображения копирует int(x) в rect.x. Ограничение границ применяется к float до этой синхронизации.

При скорости 1,5 пикселя за кадр дробная часть накапливается и не теряется при каждом шаге. Ограничение float также не позволяет накопленной дроби вытолкнуть объект за край.

- [20261021000003](../vault/20261021000003.md) GDD - Горизонтальное движение ограничено игровым полем. Поддерживает правило движения внутри поля.
- [20261021000016](../vault/20261021000016.md) SDD - Флаги удержания отделяют события от движения. Получает направление из флагов ввода.
- [20261021000021](../vault/20261021000021.md) DEV - Проверка правила начинается с наблюдаемого результата. Даёт отдельный граничный случай для проверки.
- [20261021000034](../vault/20261021000034.md) IDEA - Временной шаг отделит движение от частоты кадров. Нужно сохранить при переходе к скорости в пикселях за секунду.

## Групповая коллизия начисляет очки за все цели

[Карточка 20261021000018](../vault/20261021000018.md).

groupcollide удаляет пересекающиеся пули и цели, затем контроллер суммирует все удалённые цели и начисляет цену каждой. В ЛР6 одна пуля может уничтожить несколько перекрывающихся целей.

Такое поведение прямо проверяется test_one_bullet_scores_every_overlapping_target. Оно шире проектной формулировки ЛР5 «одно попадание уничтожает одного пришельца» и должно учитываться при согласовании документов.

- [20261021000004](../vault/20261021000004.md) GDD - Ограниченный залп делает прицеливание значимым. Связывает техническую коллизию с решением о выстреле.
- [20261021000006](../vault/20261021000006.md) GDD - Пустой флот служит границей уровня. Запускает переход после удаления последней цели.
- [20261021000009](../vault/20261021000009.md) SRS - Четвёртая активная пуля не создаётся. Освобождает занятые слоты пуль.
- [20261021000022](../vault/20261021000022.md) DEV - Расхождение кода и проекта требует явного решения. Фиксирует различие между спецификацией и кодом.

## Ресурсы ищутся относительно пакета

[Карточка 20261021000019](../vault/20261021000019.md).

load_image получает BMP через importlib.resources из alien_invasion.images. Поиск не зависит от папки, из которой пользователь запустил приложение.

Если именованный ресурс отсутствует, функция поднимает FileNotFoundError с его именем. Этот контракт пригоден для понятного сообщения при диагностике поставки.

- [20261021000012](../vault/20261021000012.md) SRS - Базовая игра работает без сети. Поддерживает локальный запуск без загрузки изображений из сети.
- [20261021000023](../vault/20261021000023.md) DEV - Поставка должна фиксировать зависимости и ресурсы. Требует включать изображения в дистрибутив.
- [20261021000028](../vault/20261021000028.md) SUP - Обращение об ошибке должно воспроизводиться. Даёт проверяемые данные для обращения об ошибке.

## Порядок операций кадра влияет на результат

[Карточка 20261021000020](../vault/20261021000020.md).

Фактический кадр ЛР6: события, корабль, пули с попаданиями и переходом уровня, флот с угрозами, отрисовка, Clock.tick. Механические обновления выполняются только в активной партии.

Новый флот, созданный при обработке пуль, может обновиться уже в этом кадре. Поэтому перестановка вызовов является изменением поведения, а не только стиля программы.

- [20261021000015](../vault/20261021000015.md) SDD - Контроллер координирует объекты одного кадра. Задаёт координатора этого порядка.
- [20261021000014](../vault/20261021000014.md) SRS - Ограничение FPS не доказывает производительность. Размещает ограничитель частоты в конце кадра.
- [20261021000033](../vault/20261021000033.md) IDEA - Таймер восстановления сохранит обработку событий. Показывает, почему sleep мешает обработке следующего ввода.
- [20261021000034](../vault/20261021000034.md) IDEA - Временной шаг отделит движение от частоты кадров. Определяет место вычисления временного шага.
