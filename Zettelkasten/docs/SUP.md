# SUP: Alien Invasion

Процедуры поддержки и инструкции. Сборка из атомарных карточек от 21.10.2026.

Документ сохраняет статусы карточек. Проектные требования, выводы и предложения не являются утверждением о готовой реализации. Источники и подробные связи доступны по ссылкам.

## Обращение об ошибке должно воспроизводиться

[Карточка 20261021000028](../vault/20261021000028.md).

Полезное обращение содержит версию игры, ОС, последовательность действий, ожидаемый и фактический результат. При ошибке ресурса нужно приложить имя файла из сообщения.

Если тот же сценарий воспроизводится после чистой установки, его можно связать с исправлением и последующей регрессионной проверкой.

- [20261021000019](../vault/20261021000019.md) SDD - Ресурсы ищутся относительно пакета. Даёт точный контракт ошибки отсутствующего изображения.
- [20261021000027](../vault/20261021000027.md) MKT - Отзыв полезнее привязывать к наблюдаемому затруднению. Поставляет конкретный эпизод от игрока.
- [20261021000030](../vault/20261021000030.md) SUP - Патч должен сохранять проверяемые правила. Превращает воспроизведение в проверку патча.

## Руководство объясняет первую минуту игры

[Карточка 20261021000029](../vault/20261021000029.md).

Краткая инструкция для текущей ЛР6: нажать Play, удерживать стрелки для движения, нажимать Space для выстрела и Q для выхода. Одновременно доступны три пули; рекорд живёт до закрытия приложения.

В ЛР5 указан Esc, но в обработчике ЛР6 реализован Q. Инструкция должна соответствовать проверяемой версии; смысл запаса кораблей также нужно объяснить как число оставшихся замен.

- [20261021000003](../vault/20261021000003.md) GDD - Горизонтальное движение ограничено игровым полем. Объясняет правило движения.
- [20261021000008](../vault/20261021000008.md) GDD - HUD показывает состояние без выхода из партии. Даёт значения показателей HUD.
- [20261021000022](../vault/20261021000022.md) DEV - Расхождение кода и проекта требует явного решения. Требует сверить формулировки с кодом.
- [20261021000026](../vault/20261021000026.md) MKT - Открытая учебная поставка поддерживает разбор механик. Делает инструкцию частью поставки.

## Патч должен сохранять проверяемые правила

[Карточка 20261021000030](../vault/20261021000030.md).

После исправления воспроизводимого дефекта нужно повторить его сценарий и затронутые проверки базовых правил. Запись версии должна объяснять наблюдаемое изменение и способ проверки.

Проверка только изменённой строки недостаточна: исправление загрузки ресурса может работать из исходников, но потеряться при сборке пакета.

- [20261021000028](../vault/20261021000028.md) SUP - Обращение об ошибке должно воспроизводиться. Даёт исходный сценарий дефекта.
- [20261021000021](../vault/20261021000021.md) DEV - Проверка правила начинается с наблюдаемого результата. Определяет ожидаемые результаты регрессии.
- [20261021000023](../vault/20261021000023.md) DEV - Поставка должна фиксировать зависимости и ресурсы. Расширяет проверку на собранную поставку.
