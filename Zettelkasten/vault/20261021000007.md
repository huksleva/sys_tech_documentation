# GDD - Рекорд процесса сохраняет смысл повторной партии

Теги: #GDD #score #progression

## Идея

Рекорд хранит наибольший счёт за время работы приложения. Новая партия сбрасывает текущий счёт и уровень, но не рекорд; после закрытия приложения рекорд теряется.

## Обоснование и проверка

Такое правило даёт немедленную цель для повторной попытки без создания учётной записи и файла сохранения.

## Связи

- [[20261021000006]] GDD - Пустой флот служит границей уровня. Определяет стоимость целей на очередном уровне.
- [[20261021000011]] SRS - Повторный Play сбрасывает только данные партии. Задаёт границу сброса данных партии.
- [[20261021000008]] GDD - HUD показывает состояние без выхода из партии. Делает рекорд видимым игроку.
- [[20261021000035]] IDEA - Локальное сохранение продлит жизнь рекорда. Предлагает отдельно пересмотреть срок хранения рекорда.
