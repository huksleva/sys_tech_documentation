# GDD - HUD показывает состояние без выхода из партии

Теги: #GDD #ui #feedback

## Идея

HUD должен постоянно показывать текущий счёт, рекорд, уровень и запас кораблей. Игроку не требуется открывать отдельный экран для оценки своего положения.

## Обоснование и проверка

Название и смысл запаса нужно согласовать с реализацией: в ЛР6 три обозначают доступные замены, а не общее число допустимых попаданий.

## Связи

- [[20261021000013]] SRS - Состояние нельзя передавать только цветом. Требует читаемого представления показателей.
- [[20261021000007]] GDD - Рекорд процесса сохраняет смысл повторной партии. Объясняет смысл рекорда на экране.
- [[20261021000022]] DEV - Расхождение кода и проекта требует явного решения. Выявляет неоднозначное обозначение запаса.
- [[20261021000031]] IDEA - Индикатор залпа объяснит недоступный выстрел. Предлагает добавить ещё один показатель состояния оружия.
