# SRS - Базовая игра работает без сети

Теги: #SRS #requirements #offline

## Идея

После установки Python-зависимостей партия должна запускаться локально без сети и внешней учётной записи. Изображения поставляются вместе с пакетом.

## Обоснование и проверка

Установка зависимостей и сама игра - разные этапы. Требование офлайн-партии не означает, что первоначальное получение Python или Pygame возможно без заранее подготовленных файлов.

## Связи

- [[20261021000019]] SDD - Ресурсы ищутся относительно пакета. Обеспечивает доступ к локальным изображениям.
- [[20261021000023]] DEV - Поставка должна фиксировать зависимости и ресурсы. Фиксирует зависимости этапа установки.
- [[20261021000026]] MKT - Открытая учебная поставка поддерживает разбор механик. Влияет на способ распространения учебного проекта.
- [[20261021000035]] IDEA - Локальное сохранение продлит жизнь рекорда. Ограничивает будущий рекорд локальным хранением.
