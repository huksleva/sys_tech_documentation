# SDD - Ресурсы ищутся относительно пакета

Теги: #SDD #architecture #assets

## Идея

load_image получает BMP через importlib.resources из alien_invasion.images. Поиск не зависит от папки, из которой пользователь запустил приложение.

## Обоснование и проверка

Если именованный ресурс отсутствует, функция поднимает FileNotFoundError с его именем. Этот контракт пригоден для понятного сообщения при диагностике поставки.

## Связи

- [[20261021000012]] SRS - Базовая игра работает без сети. Поддерживает локальный запуск без загрузки изображений из сети.
- [[20261021000023]] DEV - Поставка должна фиксировать зависимости и ресурсы. Требует включать изображения в дистрибутив.
- [[20261021000028]] SUP - Обращение об ошибке должно воспроизводиться. Даёт проверяемые данные для обращения об ошибке.
