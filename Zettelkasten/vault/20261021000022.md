# DEV - Расхождение кода и проекта требует явного решения

Теги: #DEV #traceability #requirements

## Идея

ЛР5 описывает три жизни всего, а ЛР6 хранит три замены сверх текущего корабля: завершение происходит после четвёртого попадания. Это различие терминов и поведения, которое нельзя скрыть общим словом «жизни».

## Обоснование и проверка

Для текущих карточек фактом реализации считается код ЛР6; правила ЛР5 помечены как проект. Перед изменением нужно выбрать контракт и согласовать GDD, SRS, SDD и связанные проверки.

## Связи

- [[20261021000008]] GDD - HUD показывает состояние без выхода из партии. Показывает пользователю неоднозначный запас.
- [[20261021000018]] SDD - Групповая коллизия начисляет очки за все цели. Даёт ещё один пример расхождения контракта.
- [[20261021000021]] DEV - Проверка правила начинается с наблюдаемого результата. Требует согласовать ожидаемый результат теста.
- [[20261021000033]] IDEA - Таймер восстановления сохранит обработку событий. Превращает расхождение восстановления в отдельное предложение.
