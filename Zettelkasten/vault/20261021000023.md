# DEV - Поставка должна фиксировать зависимости и ресурсы

Теги: #DEV #packaging #reproducibility

## Идея

Исходный дистрибутив игры должен содержать сведения о зависимостях и оба изображения. В pyproject.toml ЛР6 указаны Python >=3.11 и Pygame >=2.6.1,<3.0, а BMP включены как данные пакета.

## Обоснование и проверка

Установка и запуск из другой рабочей папки выявляют потерянные ресурсы лучше, чем запуск из исходного каталога разработчика.

## Связи

- [[20261021000019]] SDD - Ресурсы ищутся относительно пакета. Объясняет независимый от текущей папки поиск ресурсов.
- [[20261021000012]] SRS - Базовая игра работает без сети. Отделяет установку от офлайн-партии.
- [[20261021000026]] MKT - Открытая учебная поставка поддерживает разбор механик. Определяет содержимое учебной поставки.
- [[20261021000030]] SUP - Патч должен сохранять проверяемые правила. Требует повторной проверки после упаковки патча.
