# SUP - Патч должен сохранять проверяемые правила

Теги: #SUP #support #release #testing

## Идея

После исправления воспроизводимого дефекта нужно повторить его сценарий и затронутые проверки базовых правил. Запись версии должна объяснять наблюдаемое изменение и способ проверки.

## Обоснование и проверка

Проверка только изменённой строки недостаточна: исправление загрузки ресурса может работать из исходников, но потеряться при сборке пакета.

## Связи

- [[20261021000028]] SUP - Обращение об ошибке должно воспроизводиться. Даёт исходный сценарий дефекта.
- [[20261021000021]] DEV - Проверка правила начинается с наблюдаемого результата. Определяет ожидаемые результаты регрессии.
- [[20261021000023]] DEV - Поставка должна фиксировать зависимости и ресурсы. Расширяет проверку на собранную поставку.
