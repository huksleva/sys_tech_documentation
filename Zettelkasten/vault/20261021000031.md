# IDEA - Индикатор залпа объяснит недоступный выстрел

Теги: #IDEA #idea #ui #mechanics

## Идея

Показать в HUD три сегмента слотов: занятый слот заполнен, свободный пуст; рядом число свободных слотов. Гипотеза: игрок быстрее поймёт, почему Space иногда не создаёт пулю.

## Обоснование и проверка

Связка «лимит залпа + непрерывный HUD + эпизод непонимания» дала эту идею. Проверка прототипа: при 0/1/3 активных пулях сегменты соответствуют группе; в пробной партии игрок объясняет причину отказа до подсказки.

## Связи

- [[20261021000009]] SRS - Четвёртая активная пуля не создаётся. Определяет единственный источник числа занятых слотов.
- [[20261021000008]] GDD - HUD показывает состояние без выхода из партии. Даёт место для индикатора.
- [[20261021000013]] SRS - Состояние нельзя передавать только цветом. Требует формы и числа помимо цвета.
- [[20261021000027]] MKT - Отзыв полезнее привязывать к наблюдаемому затруднению. Задаёт способ проверки понятности.

## Основание

Авторский синтез связанных карточек; проверка гипотезы ещё не проводилась.
