# IDEA - Локальное сохранение продлит жизнь рекорда

Теги: #IDEA #idea #score #offline

## Идея

Сохранять рекорд в локальном JSON-файле при улучшении и читать при запуске. Повреждённый или отсутствующий файл должен давать начальный рекорд 0 и понятную диагностику без запрета партии.

## Обоснование и проверка

Идея связывает стимул повторной попытки с офлайн-ограничением. Проверка: рекорд переживает перезапуск, новая партия его не сбрасывает, неверный JSON не ломает запуск. Это расширяет границы ЛР5 и требует обновить её требование о сроке хранения.

## Связи

- [[20261021000007]] GDD - Рекорд процесса сохраняет смысл повторной партии. Задаёт текущий срок жизни рекорда.
- [[20261021000011]] SRS - Повторный Play сбрасывает только данные партии. Сохраняет правило повторной партии.
- [[20261021000012]] SRS - Базовая игра работает без сети. Исключает необходимость сетевого сервиса.
- [[20261021000030]] SUP - Патч должен сохранять проверяемые правила. Требует проверки поставки и миграции поведения.
