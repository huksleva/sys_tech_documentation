## 5. Проверка сохранности данных и создание резервной копии

1. **Контрольная правка:**
На странице `/home` сохранена строка `Контрольная отметка: 2026-09-13 14:30`.


2. **Контрольный перезапуск стека:**
Выполнено штатное пересоздание контейнеров без удаления тома данных (флаг `-v` исключён):


```powershell
docker compose down
docker compose up -d

```


После повторного входа в систему проверена доступность всех страниц и наличие контрольной строки.


3. **Логический дамп PostgreSQL:**
Создана папка `.\backups`, выполнен экспорт дампа через `pg_dump -F c` внутри контейнера, выполнена проверка целостности через `pg_restore -l` и файл скопирован на хост:


```powershell
New-Item -ItemType Directory -Force -Path .\backups
$dump = ".\backups\wiki_alien_{0:yyyy-MM-dd}.dump" -f (Get-Date)
docker compose exec -T db pg_dump -U wiki_alien -d wiki_alien -F c -f /tmp/wiki_alien.dump
docker compose exec -T db pg_restore -l /tmp/wiki_alien.dump
docker compose cp db:/tmp/wiki_alien.dump $dump
docker compose exec -T db rm -f /tmp/wiki_alien.dump

```



Утилита `pg_restore -l` подтвердила корректность структуры дампа: сформировано 194 записи (`TOC Entries: 194`, `Format: CUSTOM`, `Compression: gzip`), дамп `wiki_alien_2026-09-13.dump` успешно сохранён в каталоге `backups`.


Рис. 8. Успешное выполнение логического дампа PostgreSQL и проверка оглавления архива.

* Покажите терминал PowerShell в папке проекта.
* Выполните `docker compose ps` (покажите статус контейнеров `Up (healthy)`).


* Выполните `dir .\backups\` (покажите созданный файл `.dump`).




2. **Браузер — проверка разграничения прав (20–30 сек):**
* Откройте окно браузера в режиме инкогнито и перейдите на `http://localhost:8080/home`.


* Продемонстрируйте форму входа, подтверждая, что гостевой просмотр закрыт.




3. **Браузер — демонстрация структуры документации (40–50 сек):**
* В основном окне с авторизованным аккаунтом откройте страницу `/home`.

* Последовательно перейдите по ссылкам:
* `Паспорт документации` (`/alien-invasion/overview`);


* `SRS` (`/alien-invasion/srs`);


* `SDD` (`/alien-invasion/sdd`).
