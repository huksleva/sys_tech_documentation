## 📋 Описание лабораторной работы

Лабораторная работа состоит из двух ключевых частей:

1. **`presentation.tex`** — интерактивная научная презентация на базе пакета `beamer`:
   - Тема оформления: `Madrid` с цветовой палитрой `whale`;
   - Соотношение сторон слайдов 16:9;
   - Многоколоночная компоновка материалов (`columns`);
   - Пошаговые анимации и наложения списков (`overlays`);
   - Информационные блоки (`block`), листинги исходного кода (`listings`) и гиперссылки (`hyperref`).

2. **`poster.tex`** — крупноформатный академический постер формата **A0** на базе пакета `tikzposter`:
   - Тема оформления: `Simple` с контрастными синими акцентами на чистом белом фоне;
   - Структура из 6 секций: Аннотация (Abstract), Введение, Методы генерации, Практические результаты, Анализ производительности, Список литературы;
   - Векторная схема конвейера обработки данных, спроектированная на базе движка `TikZ`;
   - Математические формулы и график метрик производительности.

## ⚙️ Сборка в Overleaf

В проекте используется компилятор **LuaLaTeX** с пакетами `fontspec` и `polyglossia` для корректной поддержки кириллических шрифтов и стандарта Unicode.

Для переключения между презентацией и постером в Overleaf:
1. Откройте меню в верхнем левом углу (**Menu**).
2. Убедитесь, что в поле **Compiler** выбран `LuaLaTeX`.
3. В поле **Main document** выберите нужный файл:
   - `presentation.tex` — для сборки презентации;
   - `poster.tex` — для сборки постера.
4. Нажмите **Recompile** (или сочетание клавиш `Ctrl + Enter`).
