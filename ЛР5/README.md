## 1. Цель и исходные данные

Цель — описать игровую концепцию, формализовать проверяемые требования, спроектировать архитектуру 2D-игры на Python/Pygame и превратить требования в конкретные задачи разработки. Остальные файлы папки `Загрузки` использованы как учебные примеры и справочные материалы. Структура документов взята из методички `Загрузки/Примерные инструкции по GDD, SRS, SDD_TDD.pdf`; перечень результатов Wiki.js и Redmine — из `Загрузки/03-Задание по документированию и управлению проектом _Alien Invasion_.pdf`. Конфигурация Wiki.js в ЛР3 использована как образец локального развёртывания.

## 2. Локальная инфраструктура

В [compose.yaml](compose.yaml) определены три сервиса: PostgreSQL 17, Wiki.js 2.x и Redmine 6.1. Скрипт `docker-init/01-create-app-databases.sh` создаёт отдельные базы и непривилегированные роли Wiki.js и Redmine. Данные PostgreSQL и вложения Redmine сохраняются в именованных томах. Порты доступны только через loopback:

| Сервис  | Адрес                   | Данные           |
|---------|-------------------------|------------------|
| Wiki.js | `http://localhost:8085` | БД `wiki_lr5`    |
| Redmine | `http://localhost:3005` | БД `redmine_lr5` |

Пароли сгенерированы случайным образом и сохранены в `.env`, исключённом из Git. Этот файл нельзя публиковать или прикладывать к отчёту. Логин Wiki.js указан в `WIKI_ADMIN_EMAIL`, пароль — в `WIKI_ADMIN_PASSWORD`; логин Redmine — `admin`, пароль — в `REDMINE_ADMIN_PASSWORD`. Wiki.js настроен без телеметрии; у группы Guests снято право `read:pages`. Проект Redmine создан приватным.

## 3. Подготовленные документы

[GDD.md](GDD.md) описывает аудиторию, игровой цикл, управление, правила потери жизни, прогрессию уровней, стартовый баланс, объекты, интерфейс и сценарии игрового тестирования. [SRS.md](SRS.md) содержит 15 функциональных требований `FR-01`–`FR-15`, 5 нефункциональных требований `NFR-01`–`NFR-05`, требования к UI и критерии приёмки. [SDD.md](SDD.md) описывает состояния игры, цикл кадра, ответственность восьми классов, хранение состояния, обработку ввода, столкновений, потери жизни и повторного запуска.

В Wiki.js опубликованы страницы:

1. [Game Design Document (GDD) for Alien Invasion](http://localhost:8085/alien-invasion/gdd).
2. [Software Requirements Specification (SRS) for Alien Invasion](http://localhost:8085/alien-invasion/srs).
3. [Software Design Document (SDD) for Alien Invasion](http://localhost:8085/alien-invasion/sdd).
4. [Стартовая страница со ссылками](http://localhost:8085/home).

Файлы Markdown в корне ЛР5 являются редактируемыми первоисточниками страниц. Повторная синхронизация выполняется `python .\scripts\sync_wiki.py`.

## 4. Управление проектом в Redmine

Создан [проект Alien Invasion Game](http://localhost:3005/projects/alien-invasion-game). На основе SRS заведены 16 задач трекера **Feature / Фича**. Каждая задача содержит действие, критерий готовности и ID связанных требований. Все 16 задач назначены единственному известному участнику команды — Леониду Александровичу Тоц. Полный список и формулировки находятся в [REDMINE_TASKS.csv](REDMINE_TASKS.csv); повторная синхронизация — `python .\scripts\sync_redmine.py`.

Декомпозиция покрывает окно и настройки, корабль и управление, пули, флот, столкновения, очки и рекорд, уровни, жизни, Game Over, HUD, выход и обработку отсутствующих ресурсов. Число задач превышает минимальные 10, требуемые заданием.

## 5. Проверка

`docker compose config --quiet` завершился без ошибок. `docker compose ps` показал три запущенных контейнера; PostgreSQL был в состоянии `healthy`. HTTP-запросы к портам 8085 и 3005 вернули работающие веб-приложения. GraphQL Wiki.js подтвердил наличие четырёх страниц; не аутентифицированные запросы страниц SRS и SDD получили `403 Forbidden`. API Redmine подтвердил 16 задач и 16 назначений на одного участника. После `docker compose restart` обе системы снова стали доступны: синхронизация Wiki.js обновила существующие страницы, а синхронизация Redmine не создала дубликатов и повторно подтвердила 16 назначений.

## 6. Управление окружением

Рабочая директория команд — `ЛР5`. Для запуска нужен Docker Desktop. В текущем локальном экземпляре `.env` уже создан и службы настроены.

```powershell
docker compose up -d
docker compose ps
python .\scripts\sync_wiki.py
python .\scripts\sync_redmine.py
```

Скрипты синхронизации допускают повторный запуск. Остановить сервисы без удаления данных: `docker compose down`. Тома базы данных сохраняются.

В ЛР5 созданы документы игрового дизайна, требований и проектирования, опубликованы страницы Wiki.js и составлен исполнимый план базовой версии Alien Invasion в Redmine. Локальный стек отделён от ЛР3 и сохраняет данные между штатными остановками контейнеров. Исходный код игры не входит в эту работу: задание посвящено документации и планированию. Адреса `localhost` доступны преподавателю только при работе на этом компьютере; для удалённой проверки потребуется экспорт страниц или отдельная публикация.
