## Порядок сдачи

1. Создать в Wiki.js страницы **Software Requirements Specification (SRS) for Alien Invasion** и **Software Design Document (SDD) for Alien Invasion**. Перенести содержимое одноимённых файлов, сохранив заголовки и таблицы. GDD можно разместить как третью страницу, если требуется часть 1 общей методички.
2. Создать в Redmine проект **Alien Invasion Game**. Перенести задачи из CSV, выбрав трекер «Фича». Поле `Исполнитель` пока содержит роль; при создании заменить её реальным участником команды.
3. Проверить ссылки между страницами, назначение задач и доступность страниц преподавателю. Добавить в этот README адреса страниц и проекта после публикации.

## Границы результата

Документы описывают планируемую игру на Python и Pygame. Исходный код игры и реально созданные страницы/задачи не входят в этот локальный комплект. Подтверждение публикации возможно только после получения доступа к экземплярам Wiki.js и Redmine и списка участников команды.
