# Alien Invasion — стартовая заготовка

Это неполная версия учебной игры. В ней сохранены структура пакета, ресурсы,
публичные имена и acceptance-тесты, но игровую механику, документацию и
инструменты качества нужно завершить в ходе работы. Не копируйте реализацию из
эталонного проекта: используйте выданное задание и тесты как границы результата.

## Установка среды

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/) и
   проверьте версию:

   ```bash
   python --version
   ```

2. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/) по
   официальной инструкции и проверьте его:

   ```bash
   uv --version
   ```

3. Установите [Poetry](https://python-poetry.org/docs/#installation) через uv:

   ```bash
   uv tool install poetry
   poetry --version
   ```

4. В корне этой заготовки создайте окружение и установите зависимости:

   ```bash
   poetry install
   ```

   Команда устанавливает [Poe the Poet](https://poethepoet.natn.io/) как
   зависимость проекта, поэтому отдельная глобальная установка Poe не нужна.

5. Убедитесь, что Poe доступен, затем запустите проект и тесты:

   ```bash
   poetry run poe --version
   poetry run poe run
   poetry run poe test
   ```

## Что ожидать в начале

Окно стартового экрана должно открываться и закрываться системным событием
закрытия. Обработку клавиши `Q` студент добавляет самостоятельно.
Acceptance-тесты намеренно не проходят: они фиксируют правила, которые
предстоит реализовать. Их падение должно быть связано с незавершённым
поведением игры, а не с ошибками установки или импорта.

Каталоги `docs/` и `docs/api/` содержат только структуру будущей технической
документации. Их содержание, настройки качества, генерацию сайта и поставку
добавляйте по выданной лабораторной работе.
