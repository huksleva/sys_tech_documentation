# Alien Invasion: техническая документация

Учебная игра на Python/Pygame: игрок управляет кораблём, уничтожает флот
пришельцев и переходит на следующий уровень. Документация подготовлена для
лабораторной работы №6 по дисциплине «Системы и технологии подготовки
технической и издательской документации».

**Версия проекта:** 0.1.0.

## Быстрый запуск

Нужны Python 3.11+ и Poetry. Команды выполняются из корня проекта:

```bash
poetry install --with docs
poetry run poe run
```

| Действие | Управление |
|---|---|
| Начать или повторить игру | Нажать кнопку Play |
| Переместить корабль | Стрелки влево и вправо |
| Выстрелить | Space |
| Завершить приложение | Q или закрыть окно |

Стрелки и Space работают только в активной сессии. Новая сессия сбрасывает
счёт, уровень, скорости и направление флота; рекорд сохраняется до закрытия
процесса. Последовательность потери кораблей объясняется в [игровом цикле](game-loop.md).

## Получение сайта и архива

```bash
poetry run poe check
poetry run poe docs-site
poetry run poe archive
poetry run poe build
python -m http.server --directory site 8000
```

Откройте `http://localhost:8000`. Сайт и локальный поиск используют поставляемые
CSS, JavaScript и системные шрифты. Во время запуска игры и просмотра сайта
подключение к сети не требуется.
